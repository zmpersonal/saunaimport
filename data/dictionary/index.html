Data dictionary

Field-level definitions for the published trade files.

FieldMeaningNotes
statusPublication statelive when a valid Census snapshot is published.
last_updatedSite dataset refresh timestampUTC ISO 8601; not the Census reference month.
latest_monthNewest released Census trade monthYYYY-MM.
codeDisplayed HTS/statistical codeMay be a 10-digit Census statistical reporting number beneath an 8-digit legal subheading.
api_codeCurrent digits sent to Census APINo punctuation.
source_codeHistorical statistical provision used for a monthly rowImportant when an HTS restructuring changes the code over time; for example, the wooden-prefabricated-building series crosses from 9406.00.4000 to 9406.10.0000 in 2017.
scope_noteCategory limitationExplains why totals are broader than sauna merchandise.
general_importsMonthly general importsNominal U.S. dollars.
consumption_importsMonthly imports for consumptionNominal U.S. dollars.
general_ytdCensus general-import YTD valueAs supplied by Census for the reference month.
consumption_ytdCensus consumption-import YTD valueAs supplied by Census for the reference month.
countriesLatest-month origin-country arraySorted by general-import value descending.
census_last_updateCensus source update fieldPreserved when present in the API response.

CSV files

trade.csv contains the monthly category time series. trade-countries.csv contains the latest country breakdown for every tracked category.

Units: monetary values are nominal U.S. dollars as published by Census. The dataset does not estimate units of saunas or adjust for inflation.
SISauna Import

Independent reference site for U.S. sauna-related trade, tariff classifications and customs rulings. Category totals are not sauna-only market estimates. Not legal, customs, tariff or brokerage advice.
