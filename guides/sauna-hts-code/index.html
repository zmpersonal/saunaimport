Classification decision guide

What HTS code applies to a sauna?

There is no single answer that covers every product sold as a sauna. Start by identifying what physically enters the United States.

Short answer

A complete freestanding wooden sauna has CBP precedent in heading 9406; a non-freestanding wood kit may be classified component by component; an electric sauna heater has precedent in 8516.29; and a portable infrared enclosure has precedent in 8516.79. The actual facts control.

Complete freestanding structure

Start with heading 9406 precedent

Ask whether the imported unit has the essential character of a complete prefabricated building: structure, enclosure and the other elements that make it occupiable and freestanding.

N304393 / 9406 research →

Built into an existing room

Do not assume 9406

N290059 rejected building treatment for a kit that relied on the existing home's framing, walls, roof and other structural elements. Identified wood components were classified separately.

N290059 summary →

Heater by itself

Electric space-heating apparatus

H179957 placed an electric sauna heater under 8516.29. The rest of the sauna kit did not automatically follow the heater.

Portable fabric infrared enclosure

Domestic electrothermic appliance

N333797 classified a portable infrared sauna set under 8516.79.0000 based on the imported set and essential character.

Facts to document before searching for a code

  1. Exactly what items are in the shipment.
  2. Whether the sauna is freestanding or depends on an existing building.
  3. Whether panels, frame, roof, floor, benches, door and heater are entered together.
  4. How complete the article is at importation.
  5. Whether a heating appliance is imported separately.
  6. Materials and construction of the enclosure.
  7. Country or countries where major manufacturing operations occur.

When precedent is not enough

If the merchandise differs materially from an existing ruling, a binding ruling request can provide a product-specific CBP determination based on the facts submitted. See the binding ruling guide.
